# 평가셋

AI 매칭이 맞는 선배를 고르는지 재기 위한 가상 데이터. 실존 인물 정보는 넣지 않는다.

| 파일 | 내용 |
|---|---|
| `data/members.jsonl` | 부원 프로필 (한 줄에 한 명) |
| `labeling/members.json` | 위 파일을 들여쓰기한 보기용 사본. `python tools/make_label_sheet.py`로 만든다. 손으로 고치지 않는다 |
| `data/questions.jsonl` | 질문 (한 줄에 하나) |
| `data/labels.csv` | 정답표 — 라벨링 기준(`docs/labeling-guide.md`, 팀 합의 후 추가)에 따라 작성 |
| `data/tags.json` | 서버 태그 목록 · 질문 분류. `python tools/sync_tags.py ../gdghost-server`로 만든다. 손으로 고치지 않는다 |

```bash
python validate_data.py     # 서버 입력 규칙 검사. 데이터를 고칠 때마다 돌린다
```

## 부원 (`members.jsonl`)

```json
{"id": "M01", "department": "컴퓨터과학과", "position": "DEV", "generation": 1, "status": "GRADUATED",
 "interests": [{"name": "백엔드", "skills": ["Spring", "DB 설계"]}],
 "experiences": ["인턴", "정규직 취업"],
 "status_note": "핀테크 스타트업 백엔드 개발자 1년차",
 "bio": "신입 백엔드 취업 준비 과정을 이야기해 드릴 수 있어요"}
```

| 필드 | 규칙 (서버와 같음) | 쓰임 |
|---|---|---|
| `interests` | 1–4개 필수, 세부 기술은 그 분야의 것만 분야당 0–3개 | 임베딩 + 규칙(선배 찾기) |
| `experiences` | 0–6개 | 임베딩 + 규칙(분류별 경험) |
| `status_note` | 0–60자, 없으면 `null` | 임베딩 |
| `bio` | 0–120자, 없으면 `null` | 임베딩 |
| `department` | `컴퓨터과학과` `데이터사이언스학과` `휴먼AI공학과` `경영학과` `전자공학과` `디자인학과` `공간환경학부` `게임전공` 중 하나 | 규칙(같은 학과) — 글자가 완전히 같아야 붙는다 |
| `position` | `DEV` `AI` `DESIGN` `ETC` | 규칙(같은 포지션) |
| `generation` | 1–99. 작을수록 먼저 들어온 기수 | 규칙(선배) |
| `status` | `ENROLLED` 재학 · `LEAVE` 휴학 · `GRADUATED` 졸업 | 규칙(졸업이면 선배) |

## 질문 (`questions.jsonl`)

```json
{"id": "Q01", "category": "JOB", "title": "백엔드 신입 포트폴리오에 어떤 프로젝트를 넣어야 하나요?",
 "body": null, "anonymous": false,
 "asker": {"department": "컴퓨터과학과", "position": "DEV", "generation": 5}}
```

| 필드 | 규칙 |
|---|---|
| `category` | `JOB` 취업·채용 · `CAREER` 커리어·이직 · `PATH` 진로 고민 · `CAMPUS` 학교생활 · `STUDY` 기술·공부 |
| `title` | 2–80자 |
| `body` | 0–3000자, 없으면 `null` |
| `anonymous` | 익명이면 질문자 규칙(학과 · 포지션 · 선배)을 쓰지 않는다 |
| `asker` | 질문자 학과 · 포지션 · 기수. 규칙 점수용. 학과는 부원과 같은 목록에서 |

### 목표 구성
- 25개, 분류당 5개, 익명 5개 이상
- 제목만 있는 짧은 질문과 본문이 긴 질문을 섞는다
- **맞는 선배가 없는 질문** 2–3개 (위 "아무도 없는 분야")
- **편향 주의:** 몇 개는 부원 프로필을 보기 전에 쓴다. 프로필을 보고 쓰면 정답이 뻔한 질문만 나와 점수가 실제보다 좋게 나온다

### 손으로 쓸 때 형식
JSON이 번거로우면 이렇게 적고 변환한다.

```
[취업·채용] 백엔드 신입 포트폴리오에 어떤 프로젝트를 넣어야 하나요?
[진로 고민] 대학원 갈지 취업할지 고민이에요 / AI 쪽으로 가고 싶은데 석사가 꼭 필요한지 모르겠어요 / 익명
```
`[분류] 제목 / 본문(선택) / 익명(선택)`
